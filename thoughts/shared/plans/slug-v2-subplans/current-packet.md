## Semantic ownership and limits

Bzlmod owns immutable reservations, operations, full states, authenticated
records, epochs and realization equality. Loading evaluates originals and
owns Path text, Need/replay, options and print. Core owns the single actual
root, ordered mutation, child quiescence, complete snapshots, adoption and
release. No DICE transaction, Starlark evaluation or mutex spans child work.
Reserve the eventual absolute root and observation instance before evaluation.
Adopt the same root with unchanged embedded paths. A fresh empty process epoch
precedes any prepared or materialization reuse. Each new operation index
performs its actual operation, including a fresh process sample for Execute.
Only its exact completed record may replay in the command.
DICE retains immutable observations. Mutation authority stays with Core.

Use the [rolling detached lease][lease]. Trusted setup attaches the incoming
lease in its owning user namespace and mints the next clone from that attached
root. The next launch awaits quiescence, complete capture and record acceptance.
Sealed Source owners retain backing without mount authority. Every trusted
file/archive/delete/manifest operation uses the same rooted FD even if the
display path is missing or refers to another tree. No keeper, Host alias,
proc reopening, copying or privileged fallback is admitted.

Keep 128 roots, 16 MiB metadata, all initial/successor states and records, and
128 Executes per transcript and per command. Keep 1 MiB per output stream,
the 30-second operation maximum, and the 64 MiB Process tree and cumulative
history discipline. Keep the 27-second Source work plus 3-second cleanup clock,
512 MiB native bank, 512 FDs, 8 GiB backing, Source64 and 256 KiB worker stack.
Keep 136 MiB XZ logical/codec bounds, 128 MiB compressed allowance, and
512 MiB/call and 1 GiB aggregate decoded limits. The [selected design][design]
owns all unchanged Source, archive, process, construction and backing limits,
exact/+1 boundaries, rooted IO and file split. Timeout, cancel, overflow and
setup failure kill and reap before disposal. Normal nonzero exits retain the
actual result and next tree, including modes, deletes and admitted literal links.

Root owns LIVE, evidence selection, native/Cargo execution and atomic
integration. Workers use disjoint inactive candidates within the selected
owner boundaries. These are Bzlmod repository execution/filesystem types,
Loading repository context/path/file effects, and Core source roots, process
ownership, filesystem progress, repository IO, source generations and private
backing/confinement leaves. Consult the [pinned API source][api], [Stage 5][stage5],
[Stage 9][stage9] and [DICE ownership][dice] for inherited contracts.
