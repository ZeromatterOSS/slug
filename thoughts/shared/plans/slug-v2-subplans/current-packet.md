## Outcome and compatibility

Admit `module_ctx.path(Label)` for a selected module extension when the
Label's root or non-generated canonical external repository has an actual
observed, materialized package route. Return a distinct selected path value with
lexical `.dirname` and one-argument `.get_child("bin/cargo")`-shaped
operations. Keep the accepted `path(String)` scratch value and download
output contract unchanged. Re-run the authentic root `cquery` and report
its next honest terminal. The `@rust_host_tools` route is generated by
rules_rust and currently requires unsupported repository-rule
`download_and_extract`; generated external Labels are deferred in this
packet. It must not fabricate that root or claim to reach cargo/rustc
path values.

Exact within the admitted route/method slice: resolve a Label through
package lookup before returning a path; do not require the target file
to exist or be declared in BUILD; add no target-specific stat/digest or
implicit watch beyond package-lookup provenance, and do not resolve
symlinks or read target content; `.dirname` and normalized relative
`.get_child` are lexical. The resulting path's physical spelling,
Unicode requirement, collision-safe identity and bounded single-child
argument are Slug-native. Multi-argument `get_child`, path-of-path,
`.exists`, `.is_dir`, `.realpath`, physical reads and execution remain
unsupported/deferred. A cap of eight distinct path Labels per selected
invocation is Slug-native; overflow fails closed. Preserve the accepted
root-Label `watch` slice as an independent content observation.
