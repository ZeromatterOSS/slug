## Candidate copies and Cargo freshness (WP425, 2026-11-07)

When copying changed candidate source into an existing shared target setup,
do not preserve older source mtimes. Cargo can retain a stale feature variant
while another test variant rebuilds. Refresh changed files or copy content
without historical timestamps, inspect compiler-artifact freshness, and repeat
affected consumer gates. A source hash and matching manifest path alone do not
prove that a cached artifact contains that source.
